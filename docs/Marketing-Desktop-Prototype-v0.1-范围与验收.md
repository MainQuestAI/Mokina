# Marketing Desktop 原型范围与验收（v0.1）

> 历史记录，已被 2026-09-14 原界面重做取代。此处完成声明、旧测试数量和旧包不属于本轮验收。当前范围见 [修订 Spec](./Marketing-Desktop-Agent-Spec-v0.2-V6.2基线.md)，实际证据见 [本轮验收](./Marketing-Desktop-Prototype-验收.md)。旧重做首页不符合 V6.2 界面继承要求，不能沿用其完成结论。

## 本轮完成边界

本入口以 V6.2 为视觉与专业流程基线，提供品牌战略、社媒内容、运营分析三类营销工作。它验证统一的工作、计划、依据快照、成果版本和跨工作复用交互。

本地真实执行：文本与 CSV 读取、CSV 聚合计算、候选版本保存、采用决定、备份导入合并、导出与刷新恢复。

情景演示：品牌判断、文案生成、工作计划建议和生成提示。页面会明确标注“情景演示”，不会显示不存在的模型调用、发布回执或外部系统写入。

不在本轮：Codex Runtime 接入、真实模型质量评估、连接器授权/权限、后端数据库、桌面安装包和真实发布。

## 验收记录

- 品牌战略：可建立无项目工作；保存计划不创建成果；两份访谈固定为依据快照；策略备忘录排除 SKU、FABE、Message House 和上市链路；可编辑为候选版本。
- 社媒内容：提供五条内容和排期表；每条使用稳定 ID，单条编辑生成候选版本，原版保留；CSV 可导出。
- 运营分析：CSV 真实计算总体互动率 5.25% → 3.875%，变化 -1.375 个百分点；明确不据此判断两类内容都变差；支持仅把选定结论带入新的内容计划工作。
- 兼容：新入口只使用 `mokina-marketing-desktop-prototype` 存储键；导入按 ID 合并，不复制已有对象；旧 V6.2 页面与离线包作为对照保留。

## 已知限制

- CSV 解析面向本轮的逗号分隔、无嵌套引号样例；复杂 CSV 应在真实集成阶段引入成熟解析器。
- 当前演示未接入真实模型；“生成演示成果”是显式的、确定性的场景结果。
- V6.2 的完整专业流程仍在独立页面中运行，Marketing Desktop 不把其上市前置条件带入三类通用工作。
