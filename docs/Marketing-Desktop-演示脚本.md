# Marketing Desktop · 原界面评审脚本（0.2.1）

2026-09-14 更新。下面三条是手动评审路线；使用同一个 V6.2 工作台，不跳转另一套产品。所有品牌/文案判断为情景演示；文件和 CSV 为本地真实操作。

## 1. 品牌战略

1. 首页点“品牌战略”，核对只填入目标，没有自动发送、载入资料或生成。
2. 点“使用示例资料”，打开“本次依据”，分别查看两份北岚生活合成访谈。
3. 可切“先定计划”，发送“先讨论受众，先不制作”。不应出现成果。
4. 打开“工作计划”，调整目标、交付项输入/输出、排除项；保存，成果数量不变。可添加第二项同类型交付、上移、删除，已有项 ID 不变。
5. 点“开始当前项”。演示进度可取消；成功后对话出现成果卡。
6. 打开成果 Canvas，发“为什么不同时覆盖两类受众？”：只解释，版本数不变。
7. 协作模式发“保留方向，再补一个对照方案”：新增独立成果。先定计划模式会加入计划，需要明确开始。
8. 对方向段落点“修改此段”，填新内容，保存候选。比较版本，主动采用；切回 v1 仍可查看、导出。
9. 输入“先到这里”：停止，不创建额外后续任务。

输入变体：另开品牌工作，在“本次依据”点“使用输入变体”。新资料中家庭有稳定小组，租住者难以持续参与，示例结果优先家庭。旧工作不变。

## 2. 社媒内容

1. 新对话 → 社媒内容 → 使用示例资料，核对事实、确认表达、旧文案三份输入。
2. 发送目标，计划保持仅五条文字与排期；不要求 FABE/MH、图片或发布。
3. 开始制作，打开 Canvas，点“收起对话”可独立读表。
4. 点第三条“缩短此条”：候选 v2，其他四条不变。也可先选中第三条再通过对话提出缩短。
5. “编辑第3条”修改日期为下周四，保存 v3；版本比较后采用。
6. 分别选择 v1/v2 下载 CSV，v3 下载文字；核对其他四行相同，指定版本而非默认最新版导出。
7. 若同一工作有两份表格且未选成果，不能只凭“第三条”猜测，应先打开目标成果。
8. 输入变体：本次依据 → 使用输入变体，只提供搬家文字清单，无答疑服务；新示例不能保留答疑承诺。

## 3. 运营分析与接续

1. 新对话 → 运营分析，用“添加本地资料”选择 `docs/fixtures/operations.csv`，或显式“使用示例资料”。
2. 核对正文4行，发送目标，计划只分析。开始并打开 Canvas。
3. 查看总体5.25%→3.875%、实用6%→6.5%、介绍3%→3%、实用曝光75%→25%，结构−1.50pp、组内+0.125pp。
4. 在来源标签可查看固定原始 CSV；不能编辑原始数据。表格导出需与原值一致。
5. 点“选择结论另开工作”，只选“内容结构与接续方向”；预览带入摘要与v1引用，确认。新工作无 CSV，旧分析仍在。
6. 制定/开始“三条内容计划”；内容只作为接续提纲，具体产品事实待另行补充，不声称实验有效。

换期与异常：换用 `operations-reordered-periods.csv`，排除旧 CSV，明确选前期“八月”、本期“九月”，再算得相同数值。换用 `operations-invalid.csv` 应提示第2行 impressions 非数值，成果数不增。

## 4. 资料、版本与恢复

- 普通文档可人工编辑；取消编辑会保留草稿，返回原成果或重新打开编辑继续。
- 本次依据 → 从其他工作选择成果 → 指定版本；先选v1建文档，再选v3建第二份，旧文档仍引用v1。
- 更换自己的资料后，不允许冒用旧示例生成。可创建普通文档、人工编辑，或排除自有资料后显式载入完整示例。
- 来源“查看”可保存为文件成果，原格式不支持预览时保留文件信息/原文件下载。
- A/B会话分别填不同草稿，切换、打开能力页、刷新后核对；模拟中切到B不能让A结果抢画布。
- 开始后立即“取消演示”，结果不新增；开始后立即刷新，显示“待重新执行”。
- 设置 → 导出备份 → 在另一浏览器/存储导入两次 → 再导出，核对ID、版本、引用、决定、提交不重复。
- 一般项目只填名称，创建两次项目内对话；成果页切换当前工作/项目全部工作范围。

## 5. 同界面专业回归

首页 → 选择上市示例 → 载入德国七类交付。可手动计划/制作，或“查看完整流程”→确认重置并播放；此按钮会清空当前演示存储，先备份自己的工作。

完整故事包括七类交付、图片成员选择、候选比较、交接、固定内部提交、退回及修订；最后内部评审通过，不能显示正式发布或CL入库。

另一条：选择项目 → 创建产品上市项目，只选“品牌官网”；创建后登记合成手工事实，核对型号/市场、保存输入快照，再制定计划和开始。只出现本产品相关工作，不出现门店或电商交付，也不混入冰箱参数。

## 6. 演示边界

不接实时模型。未覆盖请求会说明范围，可编辑计划/普通文档，不保证任意自然语言都能映射动作。真实工具配置、Runtime恢复、模型质量、正式权限和外部发布均不在本轮评审范围。

内部操作证据见 [本轮验收](./Marketing-Desktop-Prototype-验收.md)。截图是本轮实际浏览器，不代表用户已认可产品。

## 7. 0.2.1 四项修复复验

1. 品牌计划排除填“不要小红书，不要文字答疑，只做微信公众号。”，保存、开始。只生成微信公众号触点。打开成果，依次发送“先不做第二个方案”“不要另一份方案”“暂不制作对照方案”，均只回复确认。协作模式发送“保留方向，再补一个对照方案”，进度可取消；重新执行后新增独立成果。
2. 社媒先切“先定计划”，发送目标，保存计划，再发送“开始制作”；生成五条而非回到讨论。第三条缩短后对照 v1/v2，其余四条不变。再修改条数为3、渠道为微信公众号、日期为2026-09-21；目标仍写五条时必须先处理冲突。把目标中的五条改为三条，未保存就对话开始，选择保存并开始；已完成项需确认另做一份。新表及 CSV 有三条，日期21/22/23日，旧表仍在。
3. 品牌 v1 的受众段落人工改成家庭方向并保存 v2。从 v1 只选该段落另开工作，先建普通文档固定 v1；本次依据切到 v2，查看正文，再建第二份普通文档。两份文档来源和导出分别为 v1/v2；原文档不变。
4. 多交付项只说开始时选择当前或全部；全部完成后重复开始不会直接制作。未保存修改可选择使用已保存计划，回到计划时底稿仍在。演示中切新工作并填 B 草稿，A 完成不抢页面；刷新中断后查看计划重新执行。
5. 运营原 CSV 上传、计算、选结论接续。排除所有带入结论再开始应停下；从原分析重新选择“内容结构与接续方向”才能继续。未知渠道如“只做抖音”可保存计划但不能制作，可选择人工编辑。
