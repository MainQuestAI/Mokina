## 目标与边界

面向个人营销专业人士的开源Agent。一条工作链、两个自然入口：市场问题可形成分析报告；品牌、产品和KPI可直接进入Brief及策略。不强制搜索、建项目、建Brand Kit或按固定步骤制作。

Fork OpenDesign `open-design-v0.22.2`，固定提交 `73953213a6fec2c8092e8e77d229a3074aa828a9`。首轮本地Web运行，以Codex完整验收。保留其他运行适配但标明验证状态。旧原型只作行为参考，保留源码、文档及数据，不把旧演示壳并入新运行系统。

## 核心执行与保存路径

```text
目标、资料、模式 → 公共运行入口
  Ask/Plan：讨论或保存，不制作
  明确执行：固定归属、选定输入、基础版本
         ↓
  指定版本/片段解析 → 不可变输入快照
         ↓
  原Codex适配 → 临时工作副本 → 输出校验
         ├─ 取消/失败/迟到：不冒充成功，不推进当前稿
         └─ 有效输出：同一版本库的候选
                       ↓ 用户采用
                 可恢复提交 → 当前工作稿
                       ↓
         同版本阅读/HTML及PDF导出/选择性接续
```

手动编辑直接形成工作修订，不额外审批；Agent修订候选不自动采用。基础过期时保留候选并提示比较。引用解析、来源预览、导出来源说明和运行输入共用解析结果。首次成果与已有成果修订须区分，不因候选机制给所有首次创建增加审批环节。

## 顺序与并行

T1先完成。T2/T3同属daemon共用链路，顺序或紧密协调，不能分别建立第二套状态。契约固定后，方法资源准备（T6）与Web工作区（T5）可并行；T4前端资料面板与T5共享Web目录，应同一条实现线。T7集成完成后进行T8/T9。用户已授权开启一个新实施任务；上述并行安排不是额外创建多个用户任务的授权。

## 失败路径与验收证据

目前新增路径的实现及测试均待完成。

| 失败场景 | 预期处理 | 必须取得的证据 |
|---|---|---|
| CLI未安装、未认证、网络失败 | 明确缺项/失败，保留输入，不能展示成功报告 | 环境检查与真实失败操作 |
| 解析失败/部分读取/公式无缓存 | 标明具体未读内容，不用空值或零补齐事实 | 各格式反例文件与正文对照 |
| 版本不存在、片段删除、ID重复 | 停止本次引用，要求重新选择，不扩大范围 | 固定引用单元及页面测试 |
| Agent输出越界/ID丢失 | 保留基础稿，呈现可解释失败或待处理结果，不自动采用 | 输出校验与局部修改反例 |
| 取消、重复回调、工作切换 | 终态不复活，不重复入库，不抢占其他画布 | 可控进程集成及浏览器录像/截图 |
| 采用写入中断、磁盘不可写 | D9恢复或提示冲突，旧稿可回看，不提前报采用成功 | 故障注入、重启和文件读回 |
| HTML/PDF导出失败 | 保持指定版本，明确失败/回退，实际文件读回 | 下载文件、版本及版面检查 |
| 长报告或长日志阻塞 | D11先测量再修命中路径；不删仍被引用历史 | 固定负载前后结果 |
| 缺研究依据或KPI假设 | 明示事实/推断/局限，缺输入时提问，不捏造 | 配对评估原始成果及人工评审 |

- DOCX/PPTX可编辑导出、扫描件OCR及复杂Office重排：D13/D14未纳入首轮承诺。
- 全运行底座同等级认证：D12先验收Codex，保留其他适配但如实标记。
- 为性能预建缓存平台或数据库索引：D11先取得测量证据。
