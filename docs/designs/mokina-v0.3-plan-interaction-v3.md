## 本轮结果

在现有三栏工作区增加“本次计划”右侧面板。计划服务于当前目标，不另建项目管理页。用户可以不打开计划，沿用直接讨论与明确执行；打开后，则以实际保存的范围执行。

当前入口：[visual.html](sketches/2026-09-15-context-to-strategy/visual.html)。上轮完整保留在 [visual-v2.html](sketches/2026-09-15-context-to-strategy/visual-v2.html)。v1、旧灰阶、生产入口及生产数据均未改动。

沿用现有浅暖灰、白色成果工作面、紫色主动作及中文排版；本轮 frontend-design 技能仅用于面板层次、固定底部动作、滚动区域和焦点细节，不扩展视觉体系或产品范围。

## 操作约定

| 操作 | 实际行为 |
| --- | --- |
| Plan 下发送方向建议 | 打开计划面板，不制作 |
| 调整计划 | 编辑目标和不做的事情；选 A/B、上移条目、指定当前项 |
| 保存计划 | 本页保存新计划版本，条目 ID 不变，不制作成果；重复保存未变化内容不新增版本 |
| 开始当前项 | 只执行被勾选的当前项 |
| 全部制作 | 按计划顺序，只执行尚未完成的所选项；补做不覆盖已有方向的人工编辑 |
| 对话“开始制作” | 一个待执行项可开始；多项则打开面板选择范围，不能猜测；成果工作/阅读中也能调用 |
| 面板有未保存修改 | 展示已保存与草稿范围、目标和依据；选择“保存并开始”或“使用已保存计划”，不静默丢弃草稿 |
| 所选项已完成 | 不重复制作；用户明确选择“另做一轮”后才执行，旧成果保留 |
| 查看计划依据 | 显示固定正文，可返回计划；资料变化需重新讨论并明确更新计划依据 |
| 操作进行中 | 对话区域显示可取消的示例操作；后改计划不影响已固定的执行范围及版本 |
| Ask/Plan 解释 | 示例解释只回复，不产生修订或采用 |

只有一个方向时，成果面展示单方向，隐藏无效的 A+B 组合动作。之后补做另一项，进入同一方向组；各方向深化稿、版本和同版阅读仍沿用已有机制。

## 建议评审路径

1. 打开 `http://127.0.0.1:4189/visual.html`，点击“准备讨论”并发送；研究可以不选。
2. 打开“本次计划”，只选 A，保存后关闭。此时仍没有方向成果。
3. 将模式设为 Plan，发送“开始制作”。查看单方向 A，深化后切到阅读。
4. 返回计划，勾选 B；点击“全部制作”。对照未保存修改，选择保存并开始。
5. 回到方向对照，查看 A/B，再检查原 A 工作稿的编辑及采用状态。
6. 再次开始，不应重复制作；选择另做一轮后取消，旧成果仍在。

## 边界与下一步

本轮仍是有限情景交互稿：计划只覆盖预置的产品解释 A、品牌叙事 B。自由目标或新制作要求可以记录，但超出预置范围会停止，不根据关键字套稿。不支持任意增加交付类型；目标与排除项尚无通用语义解析。

计划及成果只在本页内存中保存，刷新重置，界面有明确提示。1.1 秒等待仅用于可取消演示，不是模型运行进度。真实 Skill、搜索、跨会话运行、长期 Brand Kit、上传、导出及持久化未接入；最左侧其他工作仍是布局示意。

下一步优先整体验看主线中的信息层级与操作自然度，再选定要接入真实执行的最小范围；不以本次按钮或示例行为通过宣称完整专业 Agent 已完成。
