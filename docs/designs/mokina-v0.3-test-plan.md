## 实际页面与文件验证

路由沿 Fork 工作区实际入口确定，不沿用旧静态演示 URL 充当新应用证据。

1. 问题入口：明确口径 → 分析报告 → 解释 → 选段精修 → 比较采用 → 指定版本导出；核对下载文件正文与版本。
2. 任务入口：品牌/产品/KPI → Brief → 讨论和计划 → 明确执行策略；验证不强制搜索、Brand Kit 或项目建档。
3. 接续：选择报告版本及结论 → 预览携带内容 → 新工作形成策略；核对未选内容未自动带入，旧引用未变。
4. 并行与异常：A运行时切B、编辑B、取消A、刷新或重启；状态与草稿分别恢复，无串工作和重复成果。
5. 本地文件：实际选择文件、检查载入正文、导出后打开核对；上传或下载提示本身不算通过。格式待工程范围确定后补对应样例。
6. 桌面尺寸1440×900与1280×800：导航、面板、比较视图、键盘焦点、关闭返回与滚动可用。

每条记录基线SHA、环境、操作、预期/实际、截图或输出文件、失败及待验项。真实模型、文件操作和页面证据分别记录；访问受阻保留待验。

## D13资料导入补充用例

用户已选常用资料格式，下面为待实施验证项，尚未执行。每类都通过实际文件选择核对提取正文与来源位置，不以文件上传成功替代解析成功。

| 格式 | 核对内容与错误路径 |
|---|---|
| TXT/Markdown | 中文、空文件、换行、编码无法识别时提示；文本中的指令仅作为资料内容 |
| CSV | 引号内逗号/换行、表头与行号保留；缺列、非法数值不能填零补算 |
| 文本型PDF | 多页正文与页码对应；扫描页、混合页、加密或损坏文件提示未读取部分，不冒充全文已载入 |
| DOCX | 正文顺序与基本表格；段落/表格定位可回看；未支持图形、文本框等内容明确限制 |
| XLSX | 多工作表、行列定位、日期和数值区分；公式缓存值标注，缺缓存不当零；宏不执行 |

跨格式测试：更换同名文件后新快照变化、旧成果引用不变；解析失败不把空正文当有效依据；保留原文件且可回看；大文件需显示真实处理状态，取消后不注入迟到结果。解析组件和安装依赖在实施前核验，不假定本机工具已随产品分发。
