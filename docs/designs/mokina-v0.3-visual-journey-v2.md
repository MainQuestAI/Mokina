## 交互定义

| 位置 | 本轮行为 |
| --- | --- |
| 背景资料 | 查看三份合成资料正文，选择本轮使用范围，编辑目标。研究默认不选；品牌摘录是任务资料，不要求先建立 Brand Kit |
| 讨论笔记 | 同一会话中展示目标、内部条件、外部线索和暂不能判断的内容；讨论不生成策略 |
| 建议卡 | 只准备可编辑请求；制作类请求需切到执行并发送。Ask、Plan 不自动执行 |
| 方向对照 | A 产品解释、B 品牌叙事并排比较目标、依据和取舍；两者使用同一固定背景 |
| 深化与组合 | 首次深化通过明确发送载入示例工作稿；A、B、A+B 独立保留。再次选择已有方向打开原工作稿，不重复制作 |
| 局部编辑 | 方向的“怎样服务目标”可编辑，只改变这一项。已深化稿不被上游编辑自动覆盖 |
| 多轮方向 | 新一轮另存；方向草案记录可切回旧轮，依据及旧工作稿保留 |
| 工作与阅读 | 共用所选工作稿版本。B 的标题、判断、方法解释、下一步提示与 A 区分；A+B 有独立组合表达 |
| 选择性接续 | 选中段落、指定版本、必要目标及品牌要求进入未发送请求。来源随该工作稿固定依据解析，不混入后来新选的研究 |

本轮属于有限情景演示：预置双方向要求现有产品资料和品牌摘录，这是示例内容的覆盖条件，不是产品要求所有任务必须先填品牌背景。自定义目标、取消某项必要示例资料、人工改写方向后的自动深化均不默认套稿，说明范围后保留输入。

## 评审脚本

1. 打开 `http://127.0.0.1:4189/visual.html`。不勾研究，查看产品与品牌资料。
2. 点击“准备讨论”，发送；查看讨论笔记。此时无策略草案。
3. 点击“准备两个方向”。Ask 下发送不制作；切“执行”再发送，展开两个方向示例。演示可取消。
4. 选择深化 A，发送。编辑一段，返回方向对照，再深化 B。重新打开 A，手工修改仍在。
5. 选择“组合 A+B”并发送。检查组合稿的表达安排，原 A、B 仍可打开。
6. 返回背景，勾研究。旧讨论不能直接执行新范围；重新讨论后制作新一轮方向。
7. 切回第一轮方向，阅读 A 并选择品牌故事接续。固定来源仍不含后来勾选的研究。
