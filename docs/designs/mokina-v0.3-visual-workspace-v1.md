# Mokina v0.3 · 策略工作区视觉稿 v1

日期：2026-09-15。状态：可点击视觉稿，待用户评审；不是生产实现或最终设计体系验收。

## 设计落点

沿用前六状态的三栏：并行工作、持续对话、营销成果。`visual-v1.html` 是设计评审文件，不是新的产品入口；旧线框与生产原型未修改。

工作和阅读使用同一个所选版本。工作面突出策略判断、衡量、行动；阅读面组织成连续报告，不另生成正文。品牌约束、产品事实、固定研究引用和目标在背景条按需展开，方法说明解释它如何影响判断，不成为强制开工步骤。

有 KPI 的示例必须显式载入，作为独立测算附注，不替换原策略的“产品理解”目标。背景、方法、版本、测算分别服务具体工作，不把它们做成一组管理模块。

## 评审路径

1. 打开 `http://127.0.0.1:4189/visual-v1.html`，查看首屏判断和品牌/方法面板。
2. 编辑产品信息段落，再切阅读：对应段落同步；更多操作可撤销。
3. 打开版本入口，先查看 v2，再明确采用，随后查看 v1。若先编辑了 v1，预置候选会提示基底已变，不能覆盖当前编辑。
4. 阅读中选取品牌故事，预览要带走的版本、正文、目标摘要和品牌约束；确认只准备当前对话，不自动发送。
5. 在“目标与衡量”显式载入 KPI 例子，改输入、存快照，再在同版报告末尾查看附注。
6. 进入专注阅读，再点“工作”：三栏与原输入恢复。
