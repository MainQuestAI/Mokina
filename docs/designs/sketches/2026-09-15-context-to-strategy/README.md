## 查看与操作

打开同目录 `index.html` 即可离线查看，无外部资源依赖。也可以运行：

```sh

```

浏览器访问 `http://127.0.0.1:4189/`。顶部状态按钮仅用于评审切换，不是产品导航。

1. **带入上下文**：选定研究 v2 的 R-02 片段，与内部产品资料、当前目标一起进入输入区；引用不执行。发送默认讨论请求进入状态二。
2. **讨论适用性**：对照外部线索、内部条件与目标；右侧为讨论视图，不是新增策略版本。点击“形成两个策略方向”只填入请求，保持 Ask；明确选择“执行”并发送该示例请求后进入状态三。
3. **比较策略方向**：两个方向并排展示目标、依据与取舍。可以定位讨论、准备组合请求、编辑示例文字、切换阅读视图或查看原研究。研究与策略分别保留。

研究不是必经步骤；这次只画“已有研究继续策略”的分支，未画纯内部资料起步。示例不包含真实行业排名、销量或市场调查结果。KPI 未提供时不编造数字；本图不替代 KPI 拆解流程设计。

## 实现边界

本稿展示布局和有限点击关系，不调用模型、不搜索、不创建真实工作或版本、不保存数据。文字编辑仅在当前页面内有效，刷新丢失。自由输入不会获得真实回答。组合、采用、历史比较、跨会话运行和完整 Plan 面板待下一轮设计；图中版本标签是示例，不是实现验收。
