策略判断：把“便携”转化为可验证的购买理由

以下均为推断与建议 依据产品形态、受众与渠道限制 [S1]；未引用行业研究或历史投放表现。

先测使用场景

推断：“便携”可以通过短视频展示，但展示方便携带不等于证明用户需要。

建议：从访谈中收集实际携带与使用情境，再拍摄对应内容；不要预先宣称某一校园场景是刚需。

局限：尺寸、包装和使用方式未提供，卖点表达须以实际产品为准。

价格需要价值解释

推断：只展示“89 元”不足以证明购买价值；用户的“大众价格”定位仍需消费者反馈支持。

建议：保持给定价格，观察受众如何评价产品价值、提出哪些购买顾虑。

局限：没有成本或竞品数据，无法判断利润空间和相对价格地位。

短视频先承担解释与验证

推断：短视频适合展示携带和使用方式，但画面不能让受众直接闻到香气，转化存在待验证环节。

建议：以真实产品信息回答疑问，并打通可归因的成交路径；排除线下快闪。

局限：平台、素材和交易入口尚未确认，不能预测触达或转化效果。

建议优先级：明确产品信息 → 验证受众需求 → 小范围短视频测试 → 按成交表现决定扩量。

四周安排：每一阶段回答一个关键问题

建议排期 · 尚未执行 4 周是既定周期 [S1]；以下任务顺序为本报告建议。各阶段能否推进，取决于前一阶段的验证结果。

第 1 周 / 定义

为什么会买？

核对真实产品信息；访问目标受众，记录需求、价格反馈与疑虑；明确成交入口及费用口径。

阶段产出

有记录的需求假设、真实卖点清单、可测试路径。

进入下一阶段：素材有事实依据，转化追踪可用。

第 2 周 / 测试

哪种表达有效？

开展小范围短视频测试；围绕已确认场景比较表达，尽量控制其他条件；记录观看、访问与成交。

阶段产出

同口径素材表现与购买顾虑记录。

进入下一阶段：有可归因成交；样本是否足够须另行评估。

第 3 周 / 决策

是否值得增加投入？

核对成本与订单质量。满足事先确认的成本要求才逐步扩量；未满足时修改假设或停止低效投放。

阶段产出

有证据的继续、调整或暂停决定。

不因进入第 3 周就自动增加预算。

第 4 周 / 复盘

哪些结论可保留？

汇总已发生支出、归因订单、反馈与退款状态；区分已证实发现和仍需观察的结果。

阶段产出

投入产出记录、适用边界及下一轮验证清单。

未完成售后观察的订单保持暂定口径。
