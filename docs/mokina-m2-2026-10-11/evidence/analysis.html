解释 A · 待验证假设

web 渠道自身需求增强

支持：在已提供的同币种记录中，web 从 1000 变为 1200。[sales-clean]

反证与削弱：订单数、客户数和流量均缺失；金额增加也可能仅由客单价、退款时间或记录覆盖变化构成。CNY 已知值总小计没有同步增加，且二月存在缺失。

验证方式：取得两个月同口径的 web 完整订单明细、有效订单数、退款与去重客户数，分解“订单数 × 净客单价”，再与可核验的渠道归因对应。

改变判断的证据：若统一口径后 web 增加消失，或只由金额记账时间/转渠道产生，则放弃需求增强解释；若订单与客户数也增加且完整性成立，才提高该假设的可信度，仍不等于广告因果。

解释 B · 待验证假设

渠道结构或记录覆盖改变

支持：一月有整行重复 r2；二月 social 金额缺失；other 从 0 到 300。数据缺口足以影响跨期小计。[sales-raw]

反证与削弱：没有客户迁移、渠道编码变更或补录日志；不能仅凭缺失就断言渠道迁移，也不能断言缺失金额一定为正。

验证方式：核对 r2 是否同一业务记录；补齐 r4 原始凭证；获取渠道定义和覆盖清单，按同一记录主键、币种与期间重新汇总。

改变判断的证据：若补齐后结构差异消失，优先认定原样本覆盖影响；若主键、完整性和渠道定义都稳定，而跨渠道变化仍存在，则该解释减弱，需用客户级轨迹验证真正迁移。

两种解释竞争同一组有限观察，并非已成立事实，也不排除二者同时存在。此处按 [analysis-method] 步骤 4–5 展示支持与反证。

04 / 当前选择：先核口径，再决定试验

当前建议为有条件的推断：优先完成数据完整性核对。两月、六条保留记录不够支持扩大线上营销投入，也不足以为任何计划方向排序。该建议基于 [sales-raw] 的已知缺陷和 [analysis-method] 的分析边界。

先核记录覆盖取得数据负责人的原始导出与字段说明；逐项核 r2、补 r4、确认是否覆盖完整月份和各渠道。保留更正前后映射。复核同一 2026-01 / 2026-02 窗口，不混入其他月份；若无法解释主键或缺失，停止总体跨期比较。只有重复含义、缺失金额、币种及覆盖均可追溯后，才更新金额比较。若趋势改变，撤回原样本下的方向判断。
有条件验证 web 假设完成前一路径，具备可归因的线上渠道、有效订单/客户口径与单独批准的试验范围后，才设计小规模线上内容试验。建议观察一个预先锁定的 4 周窗口，与同长度、同定义且可核实的基线比较；渠道标记丢失或基线不完整即暂停效果比较。同时获得完整流量、有效咨询、订单、退款及归因信息，才能讨论转化变化。若只增长记录金额而无可比机制，维持“不足以归因”。

05 / 未核实项与两层检查

源事实与样本限制

  • 交易真实性、币种标识、金额定义、税费/退款口径、月份覆盖和样本选择方式未核实。
  • r2 是否真实业务重复、r4 金额、USD 一月数据是否存在、渠道编码是否变更，均未知。
  • 客户数、订单数、基线、转化率、广告 CPC、产品毛利、预算批准与现有渠道可用性均未核实。
  • 这是合成、小样本、仅两期观察；无地区或行业覆盖资料，不作因果结论或市场规模外推。

专业自评 · 独立于算术

可使用范围：复查原始数据缺陷、检查排除过程、按币种重算已知值、提出后续取证顺序。

不满足的决策条件：完整可比的两月业务口径、因果识别、可核验转化与利润资料。即使数值复算无误，也不能据此认定营销有效或批准投入。

清洗代价：减少重复值对小计的影响，但不能恢复缺失数据，也不能证实首次 r2 是正确记录。补证可能改变结论。
