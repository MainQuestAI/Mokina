02　受众与待验证瓶颈

尚不能诊断真实增长瓶颈。没有用户规模、漏斗与渠道基线，以下是两种互斥的工作假设，不是调研事实。[quote: unknown / marketing-method: 步骤2]

A / 已有客户

先解决使用与购买疑问

假设既有客户已有接触入口，但线上问题未被系统解答。关注主动回应与有效咨询，不把咨询自动算成复购。

必要条件：有授权可触达的线上自有客户社群及可核实客户身份。名单人数仍未知。

B / 新潜客

让问题内容被自然发现

假设潜客在现有公开内容渠道查找信息，但缺少可读内容与清楚的线上咨询入口。以自然阅读、转发和主动咨询连接新潜客。

必要条件：已有可发布、可记录访问的公开渠道及自有社群接续入口；不以新建渠道或付费投放为前提。

03　独立可行的候选方向

方向 A / 对话驱动

既有客户线上服务

用4篇图文回应真实客户问题；6小时社群运营用于经授权的线上触达与集中答疑，4小时记录及复盘。先验证“客户愿不愿意提出具体问题”。

学习路径：触达记录 → 主动回应 → 有效咨询。反馈可在首周出现，也可能为零；互动人数不代表收入。

选择条件：已有可用客户名单和活跃社群，当前决策优先关心服务与客户问题。

风险：只覆盖既有客户；响应有自选择偏差；反复触达可能引起退订。

方向 B / 内容驱动

公开内容自然获客

制作5篇围绕潜客实际问题的图文，发布到已有公开渠道；4小时自有社群运营只承接主动进入的潜客，4小时复盘，另计2小时内部发布。

学习路径：内容访问 → 可追溯来源的首次咨询。自然分发速度未知，四周可能只能验证记录链路。

选择条件：公开渠道、发布权限、来源记录和潜客接续入口已存在，且2小时可覆盖发布。

风险：自然触达可能很少；新客身份或归因可能不可识别；发布超时须缩量。

小规模试行与停止规则

  1. 启动：只在选定方向的渠道、权限、负责人和授权就绪后，启动W1的一篇内容；这些条件当前均未被本案例证明。
  2. W1结束：若无法取得必要触达或访问记录，暂停后续内容；能记录但无人咨询，保留“0次观察”，不补造转化率。
  3. 连续两周无有效咨询：这是建议的学习阈值，不是市场基准。先在已有运营时数内复核主题、入口和记录；仍无证据支持则停做剩余内容，保留预算。B自然分发存在延迟，不能由此推断没有市场需求。
  4. 任何一周：新增行动预计令四周总内部工时超过20或现金超过18000 CNY时，不执行追加项；先缩减并重算候选。B发布预计超过2小时，按前述减少篇数规则处理。
  5. W4结束：只判断记录链路是否可用、哪些问题得到回应，以及是否有可追溯咨询。基线、归因和毛利不足时，不计算ROI、不推定销售增长由方案导致。

两周“0咨询”、2小时发布上限是本方案建议的决策门槛，不是既有业务统计。[marketing-method: 步骤6] 当前没有实际启动数据，不能填写执行KPI结果。
