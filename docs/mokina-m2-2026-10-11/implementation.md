## 行为与边界

- 保存 HTML 版本时，可选 `mokina.evidence.v1` 声明指定项目内 UTF-8 来源、SHA-256、实际读取范围、原文/摘要/数据/方法类型、限制与章节。摘要不符或缺失保留明确 incomplete 记录，不以空资料冒充成功，不自动重试模型。
- 原始来源字节、计算、问题、方法版本和摘要一起进入已有 frozenContent；没有第二可写成果库。记录含成果版本ID、原稿摘要、冻结正文摘要和自身 fingerprint。读取、指定版本导出、恢复导入/导出验证闭包；缺失或损坏明确失败。
- 指定 base 的候选/恢复沿用身份与摘要相同的冻结证据；改变声明需要重新验证来源。相同 operationId 沿原版本 owner 去重，不重新读取已经保存的证据。
- 预算从可见语义单元格复算数量×单价、总额、未用余额及内部总工时；比例检查零分母和声明的小数结果。CSV 明示重复ID、缺失、非法数值、混合单位与不规则行，不默认去重/补0；干净数据仅按单位求和。
- 版本页沿同一次版本请求显示记录，问题可进入对应章节修订。旧成果显示未检查，来源/模型阅读声明不冒充独立核实；自动规则不是专业批准。
- CLI 沿 `od files version-read <projectId> <relpath> <versionId> --json` 同步返回 `quality`。无新写接口或新重试状态机。
- 市场分析/营销方案两套 scenario 升至0.0.2，增加输入、判断步骤、证据协议、预算与容量、不同方向取舍、KPI口径、正反例、稳定章节HTML模板；方法“绑定”和实际模型读取分开证明。

范围限制：仅自动检查明确标记的数据与公式；不自动认证外部网页真实性、不从未标记的自由文案提取预算、不做统计因果推断、不替代人工专业审查。联网正文不可用必须声明摘要和限制，本轮真实样本不联网。方向组合与完整跨类型接续仍属 M3。
