## 实现取舍与复审

- 沿用原稿、frozenContent、版本清单、恢复包及原版本请求缓存；没有第二个可写成果库或质量请求链。不使用今天的文件填补历史证据。
- 保留 JSON 全文和静态附录，暂不去重。资源完整性与计算规则结论分开呈现，规则无问题不代表可离线交付或专业批准。
- 原生真实验证发现大 data URL 被 Electron 拒绝（ERR_INVALID_URL）。新增共享加载入口：大 HTML 经 IPC 进入不透明来源 Blob，小 HTML 保持原路径；保留沙箱，失败后释放 Blob，窗口由已有生命周期负责销毁。没有临时文件来源权限或额外服务。
- 浏览器乱序验证发现预览 aspect-ratio 导致加载遮罩越过列边界，挡住版本列表。修正预览尺寸约束后可在读取中正常切换，不使用 force click 绕过。
- 进行了缺陷优先源码复审并复跑受影响回归，核对完整性失败、缓存作用域、消息身份、迟到响应和原生资源生命周期。没有将本轮工程自审描述为独立 Agent/Claude 审查或人工专业签收。
