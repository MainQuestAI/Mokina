## 本轮范围和完成条件

1. 受控 HTML 条目编辑：策略文字、研究矩阵叶子单元格和预算数量/单价/工时；预算按既有十进制规则重算金额与标记的合计。只修改可寻址标记，不扩成任意 HTML 编辑器。
2. 方向组合：同一成果两个固定版本按章节选择组合，保留原方向、冻结证据和来源身份；所有操作生成候选，比较/采用沿原机制，历史基线不能绕过采用冲突。
3. 接续：明确研究、策略、活动页用途；选择的结论及背景进入原冻结快照/创建 journal，创建不发送，旧来源不随上游变化。
4. 成果导航：项目列表展开当前正式成果/候选入口，不以请求失败作为空列表；直接打开指定版本。
5. 回归：输入校验、受控编辑字节边界、精确计算、幂等/冲突、未知结果读取恢复、项目切换；来源变化和恢复包往返；研究→策略→活动页成套工程验收。1440×900、900×600 同数据视觉证据。

唯一正文为 HTML 原稿/版本；不新增成果数据库或运行引擎。确定性编辑不调用模型；Agent 定向精修沿已有章节候选。新能力要求模板标记，旧 HTML 明确回退。人工专业签收单列，不用自动检查代替。
