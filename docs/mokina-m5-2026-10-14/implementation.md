## 有边界的工作链

公开URL → 有界、安全、无登录的读取 → 项目内固定Markdown来源版本 → P04选择该来源版本/摘录 → HTML报告声明同一路径、来源versionId、SHA、支持摘录与章节 → 版本质量面板定位 → 候选/恢复/指定版本导出继续使用被冻结的字节及回执。

不引入新搜索服务，不自动核实事实真假，不执行页面脚本或指令，不扩大到动态登录站点/PDF/OCR/任意爬虫。Tavily搜索摘要仍是search_summary，不能升级成已读正文。静态HTML提取的文本明确列出未执行脚本、未读取图片等限制，使用summary而非宣称全文；支持的纯文本响应可标plain-text。沿既有public URL guard复用协议/私网/DNS/重定向保护。

- 新MokinaWebCaptureReceipt记录operationId、requested/resolvedURL、真实读取时间、HTTP状态/content-type、响应字节摘要、提取文本摘要、解析版本、读取范围与限制；可选挂到现有ProjectFileVersion与质量来源记录。严格解析，旧数据兼容，损坏字段不能静默丢弃。

- 使用既有文件版本锁与operationId。已有同ID同语义的捕获只读回或补保存，不重新抓取；改URL返回409。网络/解码/大小失败不保存伪证据。版本已保存但当前文件写出失败时返回未知/可恢复结果，通过GET查版本，再只补写出，不重跑网页请求。保护用户随后修改的当前文件。

## 实施中确认并修复的边界

- 原始来源声明没有版本身份；新增可选 versionId 后，来源选择和成果冻结消费指定版本，当前文件的修改不会代替已选字节。失败回归见 source-version-red/green 日志。
- overwrite:false 原来先 stat 再写出，有并发覆盖窗口。原子写出改为同目录临时文件 hard-link 排他发布，普通写出用 wx；两种竞争写入回归先红后绿。
- 独立复审复现错误 URL/读取范围导致字节未冻结；现先完成字节、大小、UTF8、SHA 校验并保存原文，再记录可修复的声明问题，删除原来源后仍可修复候选及恢复包往返。
- 独立复审确认运行中草稿冲突缺乏就地出口；现沿原队列刷新 native 身份，备份本窗口输入后显式读取当前草稿。未知结果可备份并准备新操作，不自动 POST。
- 真实走查发现回执 JSON 混入材料选择。规范捕获文档现在只提取网页文本、保留整个文件 SHA，并使用独立 material/web-1 解析版本；不会从手写文档授予可信回执。
