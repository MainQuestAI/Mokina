## 用户可感知改进

- 修订要求关闭重开、刷新、切换项目后保留，不自动发送；来源版本改变或旧草稿缺少版本身份时保留文字并要求重选章节。保存失败留在原面板，可重试。
- 会话历史菜单实际可点击，小窗口可选择长列表底部的旧会话；入场动效和材质保持，未发送输入切换与刷新后恢复。
- 不可读草稿显示明确错误，不崩溃、不冒充空草稿；显式保留原始备份后才能重新填写，另一窗口已经恢复的新记录不会被删除。
- 重复固定资料得到同一已保存快照；同 ID 的不同选择返回冲突，同素材并发读取不再偶发失败。
- 版本清单损坏时明确失败、保留原清单，不静默抹掉历史。
- 连接检查使用实际保存的 CLI 路径与配置，识别当前 CLI 登录状态；界面显示“已登录”，真实模型连接另行验证。
