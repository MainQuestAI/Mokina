# 本轮交叉审查

审查对象：本轮 `FileViewer.tsx` 修订草稿与保存恢复、`mokina/codex-connection.ts`、连接检查路由、相关测试和原生实测证据。审查方未实现这些产品改动；自己的快照／版本后端补丁交由主任务审查。

发现并关闭一项阻断：草稿读取原先只捕获 JSON 语法错误，不校验字段类型。坏 JSON 被显示为空草稿，新增自动保存可覆盖原记录；合法 JSON 的数字 `prompt` 则在 `revisionRequest.trim()` 渲染时崩溃。`revision-corrupt-red.log` 记录两个失败用例及该 TypeError。

修复后复审：草稿要求对象形状与字符串字段；损坏记录显式显示错误、禁止自动写入和生成。用户点击“保留备份并重新填写”后，先逐字保存原始记录，再通过现有 `mutateDurableRecord` 比较原值并删除；备份失败或原值变化均不授权覆盖。异步完成使用现有 scope／active 检查。当前完整修订恢复测试 `27/27` 通过，见 [`revision-draft-final.log`](../../output/maturity-2026-10-11/revision-draft-final.log)。
