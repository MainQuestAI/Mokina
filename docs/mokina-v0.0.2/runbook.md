## 安装与启动

1. 双击 dmg，把 `Mokina.app` 拖入「应用程序」（或任意目录）。
2. 首次启动：右键→打开（未签名包的常规步骤）；之后可直接双击。
3. 应用内不要求 OpenDesign 账号；本地浏览、编辑、导出不依赖网络。

## 外部依赖（一次性前置）

| 依赖 | 必需性 | 说明 |
|---|---|---|
| Codex CLI + 登录 | 生成任务必需 | 由你自行安装并登录；Mokina 只探测，不代装、不代登录、不读取凭据文件内容 |
| 模型网络 | 生成任务必需 | 任务期间访问所选模型的端点；离线时仍可浏览项目、人工编辑、导出已有版本 |
| 网页检索 | 可选 | 只有你在任务中显式启用时才发起请求；使用时结果带 URL 与访问时间 |

诊断：`GET /api/mokina/diagnostics`（或 CLI `od` 等价通道）输出脱敏报告：产品/构建/平台/运行状态 + 网络依赖清单与下一步动作；默认不含正文、令牌与绝对路径。

## 主要工作路径

1. 首页输入营销任务，或选入资料（资料与背景面板：预览可读范围 → 勾选段落 → 冻结为任务快照）。
2. 发送后，运行依据可见：本次提供了哪些摘录、限制与未纳入原因；已提交给模型的回执随运行状态返回（`mokinaContext`）。
3. 成果工作区：预览为主、对话可收起；单章修订生成候选 → 比较（原文/候选并排、非所选章节字节一致性、数值变化提示）→ 显式采用。
4. 版本面板：当前/历史/候选均可指定版本导出 HTML/PDF/ZIP；文件名带版本与状态（如 `-v2-historical`）。
5. 接续：选结论 → 目标任务（讨论/活动页）→ 创建新项目草稿（不自动发送）。
6. 恢复：项目恢复包导出/导入（CLI：`od mokina recovery export|import`），导入创建新项目，不覆盖现有数据。
