## 六、缺陷清单（app 侧）

1. **D1（严重）首页资料入口路由错误**：首页输入区下方「资料与背景」按钮、「添加 → 引用其它项目」均整页跳转到「设计体系」页面（复现 3/3，AX 索引与像素点击均复现）。期望：打开资料选择面板/项目素材选择器。影响：任务 A 预选旧项目素材的原生路径完全阻断。
2. **D2（中）接续项目首次打开卡死**：创建接续项目后首次从项目切换器打开，工作区长时间停在「正在加载工作区…」（>5 分钟，渲染进程高 CPU），cmd+r 无效；完全退出重开后同一项目秒开（00:19）。复现 1/1，恢复方式=重开 app。证据：21-taskB-continuation-stuck-loading.jpg / 22/23。
3. **D3（轻微）成果预览偶发白屏**：coffee-campaign.html 生成后预览区持续白屏（标签切换、刷新均无效），重开 app 后同一成果渲染正常（27）。期间聊天内缩略图渲染正常。证据：B3 阶段截图（session media）vs 27。
4. **D4（轻微）Web 内容 AX 树间歇不可用**：多次出现 AX 树只剩菜单栏（element_count=14），System Events 查询超时（-1712），截图与点击仍正常，稍后自行恢复。影响自动化可测性，不影响真实用户。

UI 文案/交互问题（不阻塞）：
- 「下载为 .zip」默认文件名为 `coffee-launch-plan-·-接续.zip」，项目名中的间隔号「·」出现在文件名中略显突兀。
- 接续草稿预填指令「先确认页面结构；我明确要求时再生成自包含 HTML」与用户「直接生成」的意图可能造成额外一轮澄清（实际出现一轮澄清卡）。
- 项目切换器中同名旧项目较多（多个「PR4 安装包工程验收」「index · 接续」），新建接续项目初始名为「未命名」，不易区分。

## 七、驱动限制（不计入 app 缺陷；均 0 绕过）

- type_text 在 AX 树坍缩期间对首页/项目输入框注入不稳定。
