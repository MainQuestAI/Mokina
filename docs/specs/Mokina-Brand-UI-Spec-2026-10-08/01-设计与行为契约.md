# 设计与行为契约

## 品牌和范围

A 图形沿用现有路径，不削瘦、不重画成 M、不添电光色、火花或默认旋转。assets/brand-candidate 的 8 个 SVG 是第二轮精修候选，黑白各含 mark/wordmark/horizontal/stacked。发布前以用户选定 hash 为准。

拟新增 `MokinaBrand` 仅接收 variant=mark|wordmark|horizontal、size、className、decorative；不接受业务 agentId。decorative 默认 true 并 aria-hidden；独立身份位置输出可读 Mokina 标签。inline SVG 用 currentColor，无外链/脚本，viewBox 原样保留。页面 logo 有现成相邻名称时不重复播报。实际 Agent/模型选择器保留供应商品牌；只有明确产品助手身份映射时用 Mokina，无法判定的角色保持现状。

## 本轮主题范围（D15=A，用户已确认）

本轮产品仅交付浅色主题，保留现有Web首帧与原生窗口浅色策略，不新增主题切换或主题配置迁移。下表深色值及D9深色按钮数值仅作为设计预备和静态样张检查，不计作产品已支持深色或本轮运行验收；不为预备值修改生产主题入口。Logo在深色承载底的资产检查继续保留，它不等于深色应用主题。

## 产品界面旧品牌清理（用户新增要求）

本轮Mokina产品自身的加载动画、启动/加载文案、功能菜单、导航、设置、关于、窗口标题、提示、tooltip及accessible name不得残留OpenDesign、Open Design或open-design品牌露出，匹配不区分大小写。产品称谓替换为Mokina；纯装饰旧字标移除，使用已选A资产；首页Logo按D13静态显示。全部实际支持语言及回退字符串都纳入检查，不只改中文。

具体分工与发现见05-旧品牌清理.md。内部包名、IPC、持久化键等不做全文替换；用户文件和历史成果不篡改。**D14=A**：Mokina中移除上游Cloud、登录充值、社区及官方支持等服务入口，保留本地/自配模型；旧配置、错误恢复及可达性验收按05执行。不得把真实外部服务改称Mokina服务。发行包中的许可证与来源文件保留。

## 标题角色（D7=A，用户已确认）

标题按用途分层，以下契约优先于原型历史快照中的普通页面标题值；不再用统一28px覆盖所有标题。沿用系统字体；深色预备沿用相同字阶。

|角色|大于760px视口|不大于760px视口|适用边界|
|---|---|---|---|
|首页展示标题|clamp(42px, 4.35vw, 68px)，行高1.3，字重600|40px，行高1.3，字重600|首页目标标题，不用于工具条或对话消息|
|普通页面标题|28px/36px|28px/36px|项目、资料等应用页面标题|
|成果文档主标题|clamp(28px, 2.55vw, 40px)，行高1.4，字重600|28px，行高1.4，字重600|应用控制的成果阅读排版；不重写用户文件或带自身样式的嵌入内容|

首页和成果标题的具体表达式、行高、字重及760px阈值忠实引用 `references/prototype/design-system/liquid-pages.css:244,275,303–316`。760px在此仅定义标题排版切换，不决定整个工作台的布局断点。长标题自然换行，不固定高度裁切。正文、摘要和章节排版不由D7扩展批准。

## 正文角色（D8=A，用户已确认）

- 应用操作文字保持14px/22px。
- 应用控制的成果阅读正文段落和列表使用15px、行高1.9（28.5px），本轮浅色各视口一致，深色预备沿用相同字阶。该值延续原型正文尺度，并把列表行距与段落统一。
- 限定到成果阅读容器中的正文段落与列表，不设置全局p/li覆盖。用户文件、自带样式的嵌入内容、代码块、表格维持各自排版。
- 摘要、章节标题不属于本条决策，不以正文规则覆盖；继续按其已有角色核对。

## 主按钮状态（D9=A，用户已确认）

只在Mokina产品作用域应用下表；危险、成功等语义操作维持原语义token。不要仅替换默认背景而遗漏共享Button CSS module和裸button规则中的hover/active覆盖。

|状态|浅色主题|深色预备（不实施）|
|---|---|---|
|default|action #0071e3，on-action #ffffff|action #2997ff，on-action #111111|
|hover|color-mix(in srgb, action 92%, black)|color-mix(in srgb, action 92%, white)|
|pressed|color-mix(in srgb, action 86%, black)|color-mix(in srgb, action 86%, white)|
|focus-visible|叠加既定2px focus外环，offset 2px|同左，使用深色focus值|
|disabled|保留真实disabled；沿既有bg-subtle/text-faint及透明边框，取消hover/pressed反馈|同左|

hover/pressed文字保持on-action；有可见边框时与背景同步。颜色混合比例是同色系反馈的实施参数。disabled优先于交互态；既有加载禁用门控不变。核对来源：`open-design/apps/web/src/styles/primitives.css:42–54,128–134`及`open-design/packages/components/src/button.module.css`，两处旧中性色均须核查，不能改共享上游产品外观。

静态sRGB计算见button-contrast.json：六种可用状态的文字对比度均超过4.5:1；这不是浏览器最终样式或用户视觉签收。

## 图标契约

保留 Icon/RemixIcon 语义入口，不新增运行时图标库。24×24 grid，16/20/24px，圆端线性图形以1.65px为初始值；按像素实际校正。纯图标按钮必须 accessible name、tooltip、focus-visible；**D10=A：纯图标按钮在桌面及窄屏的实际命中区均至少44×44px**，图形仍为16/20/24px。通过内边距或按钮自身布局盒扩大命中区，不使用互相重叠的透明覆盖层；密集工具条必要时换行，不挤压相邻动作。输入器和窄屏关键操作原44px要求保持。此条仅调整应用图标按钮，不修改画布对象或用户文件内容。装饰 SVG aria-hidden。完整映射见 icon-map.csv；原型 21 个键只是风格参照，已有等义图标可保留，避免凭“统一”重绘每个图形。

## 辅助技术状态通知（D12=A，用户已确认）

这是现有读屏支持的验收规则，不新增语音播放、TTS或产品播报开关。普通用户界面不会自动出声。

- 资料准备、完成、待确认及接续状态使用polite通知，状态语义实际变化时播报一次简短摘要；普通重渲染、提示排序变化和相同storage事件不重复播报。
- 用户操作失败使用一次alert通知；同一错误不得同时从父status与子alert重复发出。保留完整可见错误及处理动作。
- 文件名单、排除原因与详细说明保持可读和可访问，不随每次更新整段重复朗读。
- 不自动移动焦点，不改变可见提示顺序、项目/会话过滤、禁用条件和发送门控。去重只属当前界面通知，不新增业务状态或持久化缓存；新的操作再次失败仍应通知，不能永久屏蔽同文案。
- 以真实VoiceOver核对“准备→需确认→ready”、恢复失败、多提示共存与切换项目，记录实际播报和焦点；DOM角色检查只能证明结构，不能代替读屏验证。

## 不可改变的数据与交互事实

- 继续使用 projectId + conversationId + workspaceKey 隔离；身份变更后不得把异步结果写回另一项目界面。
- snapshotId/generation、clientRequestId、operationId、journal/CAS/Web Locks 的处理归现有 runtime；UI 不加第二份缓存或“已保存”标记。
- 未知不显示失败，不新建 run 重试；明确拒绝才按现有允许路径显式重试。
- 排除文件必须明确确认；源变化409必须重新读取/重选；不自动扩大选区，不冻结未选段落/表格。
- 接续“恢复原目标”保留 targetProjectId 与 conversationId；重开草稿不自动发送。
- 当前/历史/未采用候选的身份和导出目标不可混用；缺资产时展示真实失败，不能退回当前版本冒充成功。
- 客户 Brand Kit、用户上传 SVG、作品文件、历史产物、恢复 manifest 和供应商标识不做品牌替换。UI 变更无数据迁移。

具体状态见 state-matrix.csv。该文件是显示规范，不是新增后端 enum；实际状态通过现有分支适配。
