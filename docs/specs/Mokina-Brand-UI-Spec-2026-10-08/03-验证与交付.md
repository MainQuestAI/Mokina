## 执行位置和命令

以下是开发后的运行入口，本次文档整理未运行产品测试。仓库根 package.json 是旧演示工程；不要用根 npm test 证明真实产品通过。

cd open-design
pnpm guard
pnpm typecheck
pnpm i18n:check
# S03 首页准备与输入

S01 纯 SVG 使用解析/外链检查和真实像素，不写复述路径的业务测试。S02 补颜色对比、焦点、edition隔离和长文性能证据。S06 使用现有 desktop/pack 的资源、identity、splash 测试入口，新增 Mokina profile 分支的实际回归断言；最终 CI 沿 `.github/workflows/ci.yml`，不得为了通过删除原断言。新视觉截图必须从生产页面获取。

## 分层验收

| 层级 | 必做证据 | 不能替代 |
|---|---|---|
| 静态资产 | SVG解析、8母版hash、派生格式/尺寸、无脚本外链 | 屏幕小尺寸观感 |
| 浏览器 | P01–P08、state-matrix全部状态、焦点/菜单、长文滚动、列宽拖动、浅色产品主题（深色仅预备样张，不计运行验收） | native持久化/系统图标 |
| 实际新候选 | 新旧profile、真实双窗口、首页首次保存失败、精确选区、恢复、外部HTML/ZIP/PDF打开、绘画重开、冷启动 | 用户审美和专业质量 |
| 用户 | A精修母版确认、三场景及全链视觉确认、专业产物独立签收 | 技术回归 |

截图至少1280×720和1440×900，关键布局另测1280×800；当前桌面最小窗口为900×600（desktop/src/main/runtime.ts:2260–2261）；实施时复核实际限制，并记录Web内容区实际尺寸。390×844仅为窄屏健壮性，不宣称移动平台发布。单页开弹窗验证焦点，不能以多iframe总览替代。

每条 acceptance 证据记录 command/scenario、timestamp、source_sha、candidate_version、platform、profile类别、结果、截图/日志路径。包含客户材料的证据不进入公开仓库。依赖授权业务资料的验收可以列 pending，不以合成fixture冒充真实业务。

## 停止条件与回退

发现输入丢失、重复run/项目、错误版本导出、客户内容被改、跨会话串写，停止该包集成并修复；视觉不满意不删除已有历史数据。旧版本安装包和数据备份保留。无 schema 迁移意味着回退是还原UI/资源提交，但仍需实际验证旧数据可读。

S07 最终候选缺任一必需 native/用户证据，结论为“待验候选”，不能写“品牌更新完成”。跨平台未构建项不阻塞约定的macOS范围，但必须列明未验。
