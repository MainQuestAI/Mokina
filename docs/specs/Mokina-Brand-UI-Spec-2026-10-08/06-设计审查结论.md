## 复用与既有契约

- 复用Icon/RemixIcon、共享Button及既有菜单/焦点管理，不增加运行时图标库或第二状态系统。
- 非主按钮沿既有primary-ghost/ghost/subtle/secondary的默认、hover、active、disabled状态；01已确认focus规则优先。来源：packages/components/src/button.module.css。主按钮只按D9覆盖Mokina作用域。
- 资料面板、准备及恢复错误保留可见文字与role语义，播报去重按D12。加载禁用、错误分类与恢复门控沿真实组件，不从原型虚构统一loading/error按钮。
- 01的区块18/26指应用界面区块；成果文件自身样式继续保留。原型摘要/章节参数属成果参照，不把18/26全局覆盖到用户成果。D7/D8仅在应用控制的阅读样式范围生效。
- IA：导航 → 当前项目协作/输入 → 成果阅读/版本；首页 → 项目 → 资料选择/制作 → 修订比较 → 显式采用/指定版本导出。结构图与旅程见04。
