## 开发任务

1. P03/P05/P06/P08 统一导航、协作、正文三层；正文白/深实底，工具条独立。保持列宽拖动、滚动位置和成果切换行为。
2. 工具条直接标明当前正式稿/历史版本/未采用候选及版本标识；采用候选保留显式动作。只读历史不能出现会误导覆盖正式稿的主按钮。
3. 修订比较在宽窗并列；窄窗使用可切换原稿/候选区域，标签与采用按钮始终可达，不在窄窗隐藏风险信息。
   - **D11=A（用户已确认）**：修订比较弹窗分为顶部标题/关闭、中间内容、底部取消/采用三区。顶部与底部保留在弹窗布局内可见，仅中间的说明、比较与差异内容纵向滚动；使用布局分区而非覆盖正文的悬浮按钮。长要求、版本标签、风险说明完整保留；保留采用禁用条件及现有请求行为。
   - 延续现有比较视口断点：大于860px并列，不大于860px切换原稿/候选；该阈值不复用首页1200px布局断点。顶部和底部允许标签换行，但不得把内容或操作挤出弹窗；中间区需允许收缩和滚动。
4. 版本选择与导出使用同一目标身份；所有失败/取消以实际响应渲染。长文件名换行或截断配完整提示，不推出窗口。
5. 空项目、无成果、运行中、失败、有历史版本分别设计；不以新营销首页取代现有任务可达入口。
   - **D5=A（用户已确认）**：尚未发送且无正式成果的初始空项目，成果空白区显示“还没有正式成果”，说明“写下这次要完成的内容，发送后开始制作。”；主按钮“填写制作要求”只聚焦当前项目输入器。不得创建项目、自动发送、覆盖或清空草稿；资料入口继续保持可达。运行中、结果未知、失败和既有成果未选中文件不套用此空态。

   - **D6=A（用户已确认）**：首次制作运行中且尚无正式成果，显示“正在制作首份成果”，说明“完成后将在这里显示。进度可在协作区查看。”；使用实底文字说明，不使用骨架或虚构百分比。沿用协作区停止入口，不新增停止/重试按钮，不自动跳焦点，不改运行门控；已有正式成果在后续运行中继续按现有行为展示。
