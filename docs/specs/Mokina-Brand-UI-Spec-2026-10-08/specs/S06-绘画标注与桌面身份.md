## 开发任务

1. 绘画入口、Mokina 头像、生成过程品牌位、标注浮条统一；Excalidraw 自管图标优先保留，只使用可靠主题/扩展接口。没有扩展口则记录“引擎保留”，不靠脆弱DOM替换。
2. 实测 select/hand/pen/eraser/shape/arrow/text/undo/redo/zoom/save/close。clear 类破坏操作保持原确认行为。图标说明不能遮挡画布或夺走快捷键。
3. 从同一确认母版生成 macOS PNG/icns 与对应 iconset；保留生成脚本、尺寸、hash。系统承载底形与裸mark分别管理，Dock实际像素验收。
4. 在 product-profile 的 Mokina 专属资源分支选用新资源；不覆盖 OpenDesign 默认公共图标。splash 离线/服务器未就绪时同样可见，不等网络请求才显示品牌。
   - **D17=A**：Mokina桌面启动使用静态A图形与内联资源，不运行Logo扫描，不依赖WebGL；保留真实启动阶段、最小展示时间及完成判断。上游profile维持原扫描和回退。现有扫描测试仅继续约束上游分支，另补Mokina静态/离线分支，不删除共享启动阶段回归。
5. Windows ICO/Linux PNG 可产出资源并静态检验；没有真实构建即标未验，不作为本轮macOS交付承诺。
6. 设置、关于、安装说明及活动截图随候选更新；历史证据不改。导出内容不添水印，恢复manifest不改。
7. 绘画/图片生成入口若产品不可达，给出定位和明确不适用证据，不新造绘画引擎或图像生成后端。
