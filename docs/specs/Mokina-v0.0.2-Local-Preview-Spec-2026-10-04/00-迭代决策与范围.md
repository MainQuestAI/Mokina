# 00｜迭代决策与范围

## 0.1 发布裁决

下一版建议命名 **Mokina V0.0.2 Local Preview**，发布版本 `0.0.2-local.1`。不把 PR3 等同于 V0.0.2 完成，不为制造版本进展提前跳到 V0.0.3。V0.0.3 留给真实使用后的能力扩展。

产品定位不变：面向营销专业人士、以项目和成果为核心的通用 Agent Workspace。营销能力是其擅长领域，不是限制用户必须沿固定流程操作的业务系统。原生 OpenDesign 宿主是被复用的实现基础，产品面对用户的名称、默认入口、数据归属、更新行为和交付方式必须属于 Mokina。

## 0.2 “独立可运行”的边界

| 维度 | 本版必须达到 | 本版不承诺 |
|---|---|---|
| 独立产品 | Mokina.app、独立身份与数据、Mokina 默认界面、自己的说明与版本 | 清除所有内部 `@open-design/*` 名称、重写底座 |
| 独立运行 | 打包内含生产 Web、daemon、所需 Node/sidecar/资源；不依赖 git checkout、pnpm、next dev 或用户终端中的服务 | 不依赖任何外部模型能力、离线大模型推理 |
| 模型连接 | Codex 为验收主通道；识别已有 CLI/登录状态，明确缺项，Finder 环境能运行 | 本版实现新的 OpenAI API 客户端、多 harness 路由器、所有模型验收 |
| 本地数据 | 本机保存项目、资料、版本、草稿；重启恢复；可导出项目恢复包 | 云同步、多人协同、账号体系、跨设备运行恢复 |
| 营销价值 | 两个既有手动场景 + 开放式任务；真实方案、修订、活动页与小型数据任务 | 全套营销自动化、社媒直接投放、CRM、BI 平台 |
| 交付 | 明确版本的 HTML、PDF、ZIP；下载后可独立打开 | 新增完整 DOCX/PPTX/XLSX 成稿生产线 |
| 发行 | 用户目标 Mac 的本地预览包，真实 Finder 启动和使用通过 | 未经验证的跨平台支持、自动更新、已公证的公开分发 |

CLI/账号属于明确的一次性外部前置；产品日常使用不得要求用户不断回源码目录启动服务。无模型或断网时，打开项目、查看原件/版本、人工编辑和导出仍应可用。首次登录、安装 CLI 或联网真实任务不能由应用静默执行。

## 0.4 三个产品验收任务

**A｜从资料到方案。** 上传合成品牌与渠道资料，提出预算和禁止渠道约束，获得有取舍、有来源、有行动与度量方式的方案。再将预算改为原来的 60%，验证建议发生有根据的调整；不允许只改标题和数字。

**B｜从方案到交付。** 在指定旧版方案中只选两个章节，补品牌规范和素材，创建独立接续项目但不自动发送；明确制作后形成活动页，修订一章、比较、采用，导出旧版与新版。上游后来变化不改变下游已冻结内容。

**C｜开放式营销数据任务。** 上传小 CSV，计算两期转化指标，区分未知与零、加权与简单平均，解释候选驱动因素，选定一条结论进入新的可编辑接续草稿。此任务用于证明通用性，不建设独立分析工作台。
