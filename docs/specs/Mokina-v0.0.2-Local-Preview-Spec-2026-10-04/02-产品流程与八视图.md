# 02｜产品流程与八视图

## 2.1 主路径

安装并启动 → 可选连接 Codex → 直接输入任务 → 可选选择资料/背景 → 显式发送 → 查看公开执行进展与成果 → 人工编辑或单章修订 → 比较候选并显式采用 → 从选定版本接续新工作 → 导出与重开。

没有资料也能开始讨论；没有品牌规范也能先做策略。用户要求“讨论”时不制造正式成果；明确要求“交付”时调用真实制作链。选择场景、选择资料、点击“修订章节”、打开“继续制作”本身均不调用模型。

首次配置不能挡住离线项目浏览。默认显示中文，保留既有语言切换；接入第三方模型或高级工具沿用原设置页面，不建设“模型管理平台”。

## 2.2 八视图实施契约

| 视图 | 复用位置 | 必须具备的行为和状态 |
|---|---|---|
| P01 首页 | HomeView/HomeHero/Composer | 一个主要任务输入；两个手动场景“市场与竞品分析”“营销方案”；资料/背景为辅助入口。没登录时可保存草稿并去连接设置，不能丢文本。首页不重复最近项目卡片墙。 |
| P02 项目目录 | EntryNavRail/原项目列表 | 真实项目、当前成果摘要、版本身份；读取未知与零成果分开。运行中的项目仍可有可打开的当前稿。遵守 PR3 唯一/多成果/失效 tabs 规则。 |
| P03 成果工作区 | ProjectView/FileWorkspace/FileViewer | 成果主面、协作辅面；清楚显示当前/历史/候选、版本号、来源与操作可用性。后台任务错误不遮住已有成果。 |
| P04 资料与背景 | 原文件选择/设计系统入口 + 局部上下文面板 | 原件保留；解析进度、文本定位、局限、已选择摘录、未纳入原因。改选和返回不丢未发送草稿。不可读文件可保留为原件，但不能标为事实依据。 |
| P05 单章修订/比较 | 原版本面板与局部比较区 | 选择当前稿一个章节，修改要求可保存；生成前不改当前稿；候选显示基础版本和差异。宽屏并排，窄屏切换“原文/候选”，不可藏掉采用/取消入口。 |
| P06 版本与交付 | 原版本/导出面板 | 任何可读取的当前、历史、候选版本均可指定导出；不同状态有明确文件名/标识。导出动作锁定点击时的版本，不跟随之后的界面选择。 |
| P07 接续确认 | 原 FileViewer continue 表单 | 先显示来源项目/文件/版本/章节与可选品牌/素材；创建的是新项目及未发送草稿，不自动制作。创建一半可恢复到同一目标。 |
| P08 活动页成果 | 仍是通用 HTML FileViewer | 实际生成的活动页及其版本/修订/导出；不是专用第八套路由，不是新 CMS。CTA 可预览，但无真实线索接口时不能伪装“提交成功”。 |

“制作活动页”在真实管线验收前不出现在可点击生产入口。T10 通过后可在 P07 交付类型和首页“更多”出现；通用设计、品牌、素材入口继续可达。

## 2.3 资料界面文案

每项选择独立显示三层信息：

- 原件层：“已上传”，文件名、类型、大小。
- 可用内容层：“可读取”“部分可读取”“无法读取”，可展开定位与局限。
- 本次任务层：“已选择”“已加入任务快照”“已提交给模型请求”“未纳入：原因”。

不得用一个绿色对勾把上传、解析、选择、注入和“AI 已理解”混为一谈。运行依据面板优先展示已提供内容、使用的 Skill/工具、失败/缺口；只显示公开执行事件，不显示模型私有思维链。

如果输入资料在预览后变更，显示“资料已变化，重新读取后再使用”，保留用户其他输入。已经冻结并受理的任务不被新原件悄悄替换，面板可提示“此任务使用的是发送时快照”。

## 2.4 基本交互状态

| 操作 | 进行中 | 失败/不确定 | 成功 |
|---|---|---|---|
| 首次模型连接 | 正在检查已有配置；用户触发真实测试才联网 | 区分 CLI 不存在、未登录、权限/配额、网络和未知 | 显示已验证的 agent/model 与验证时间，不声称永久可用 |
| 发送 | 已保存请求、正在提交；沿 PR3 显示受理进度 | 结果待确认：仅核对原请求；明确未受理才能新发送 | 绑定原 run，流错误只影响流，不撤销受理 |
| 修订 | 当前稿可读；显示独立修订运行 | 原稿保持不变；可核对/恢复/取消 | 候选待采用，绝不自动成为当前稿 |
| 接续创建 | 固定选定来源并准备目标 | 已创建但未准备完成：恢复同一项目，不新建第二份 | 进入独立草稿，默认发送次数为零 |
| 采用 | 校验当前版本与候选基础 | 冲突：展示当前版本变化，保持原当前稿 | 当前指针变化，导航摘要立即失效重读 |
| 导出 | 锁定版本/格式，显示保存进度 | 可取消或重试同版本；不显示成功下载 | 文件存在且大小/格式可读，提供打开位置 |

## 2.5 视觉与可访问性

复用冻结包 `mokina-v0-0-2-4c39` 的 PRODUCT、DESIGN、DESIGN-BRIEF 和 MATERIAL-PARAMS，实施时解包校验 21 项 manifest。此次仅读取了 manifest 和既有迁移记录，未在本会话逐项重新审美验收冻结包。[S13/S16]

保留 PR2 已实现的 360px 协作栏默认值、316–470px 可调区间、20px 工作区圆角；旧偏好只约束当前呈现、不覆写。不得以宽屏截图为由忽略 1280×720 底部按钮、消息滚动和双栏边界。

本轮补齐八视图的冻结材质、层次、留白与操作一致性；不修改成果正文以制造玻璃效果。正文可读性优先。系统“减少动态/减少透明度”下使用简化效果；键盘 Tab 顺序、Esc、关闭后焦点返回、44px 新操作目标和可见焦点继续遵守既有基线。颜色不作为版本状态唯一标识。

i18n：新增文字走现有字典；不得仅在中文硬编码成功、失败或恢复按钮。中文和英文做实际流程检查，其他现有 locale 做键与插值合同检查；不宣称 19 种语言全部做过人工语言质量验收。

## 2.6 真实使用不应遇到的障碍

用户不需要记住 daemon 端口、项目 ID、技能包 ID 或终端命令才能完成日常流程。问题发生时界面先给下一动作，再允许复制脱敏诊断。项目与版本名不是身份键；清理历史测试项目不能影响实际工作区；任何会删除用户资料的动作必须明确确认。
