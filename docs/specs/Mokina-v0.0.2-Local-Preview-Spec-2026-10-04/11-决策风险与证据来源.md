# 11｜决策、风险与证据来源

## 11.1 已确认目标与本包设计决策

已确认用户目标：在 PR3 与既有讨论基础上规划下一轮，推进独立运行和本地实际使用，并交付可直接开发的 Spec 包。过往收敛约束：有限 fork 原生 OpenDesign；项目/成果优先；保留通用 Agent 和设计/品牌能力；不引入固定 GTM 工作流。

本包新增的**设计决策**：版本收口为 0.0.2-local.1、提前做桌面切片、独立 Mokina profile、Codex 主验收通道、仅目标 Mac 架构强验收、关闭上游自动更新、一个核心不可变上下文对象、可靠 helper 创建、项目级恢复包。它们不是“此前用户已逐项拍板”的历史事实；本次开发可依此执行，不必重新发散选型。

本包未授权：公开发布/签名服务开通/购买额度、修改全局认证、删除历史项目或客户数据、向外部服务发送客户资料、自动安装第三方工具。把执行提示词作为新的开发请求使用时，按当前用户权限和仓库规则实施。

## 11.2 风险与处理

| 风险 | 判断与处理 |
|---|---|
| PR3 仍可能继续变化 | 规划固定 53da96c；T00 重新核对最终差异和复审状态，不把 base 当包含 PR3 的 main |
| “独立”被做成源码一键脚本 | G1 必须 Finder+生产包+无源码运行；脚本不是验收替代 |
| app 改名但上游更新替换回来 | profile 包含 updater/news policy 和缓存身份；startup/manual/fallback 三路径测试 |
| Finder 看不到 CLI、认证存在 OS 存储 | 复用 adapter 真正探测，记录检测链；不以文件存在判定，不覆写用户配置 |
| localStorage 随端口变化丢请求身份 | T03 产品级持久 facade，unknown 先持久后副作用；端口冲突/升级测试 |
| PDF 在开发机可用、安装包不可用 | T05 清洁 PATH 下验证受控依赖闭包；缺失不得冒称支持 |
| 新资料逻辑变成知识平台 | 只选定片段、一次快照、一个 run 引用；无索引/同步/RAG/来源图谱 |
| 两个 helper 绕开普通发送修复 | T09/T11 复用窄 helper 和 PR3 受理，不分别再写两套幂等 |
| 输出成功但专业结果差 | A/B/C 真模型+数字核查+人工评分独立列出；结构正确不等于策略有效 |
| 过度防御影响日常体验 | 只在可能重复副作用/丢数据/权限越界处阻断；可选附件失败可移除后继续，普通浏览不强制读全项目 |
| 授权/素材版权误表述 | 素材使用状态由用户/既有记录给出；上传不等于有商用权，不伪造“已审核版权” |
| 全仓旧失败被当永久免责 | 精确基线比较；本轮影响到的旧失败不能继续标无关 |
| 恢复包导入变成数据库迁移平台 | 白名单项目数据、新项目重建、只读历史，不带可执行配置或活跃运行 |
| 视觉要求被发布压力静默删除 | G5 逐视图冻结对照；只允许系统透明/动态降级，不静默换设计方向 |
