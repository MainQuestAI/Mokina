## 权威与冲突处理

本次用户目标 → 仓库 AGENTS 的安全、目录、生命周期约束 → 本包明确的本轮产品决策 → 已批准的冻结设计 → 实际源代码和运行证据 → 历史讨论。代码现状是事实，不自动等同于正确需求。旧 Spec 的范围限制不阻止本次请求明确纳入 B2/B3/B4；旧批准也不自动批准新的公开发布、付费操作、删除用户数据。

冻结设计继续使用仓库已有 `docs/designs/mokina-v0.0.2-20261002/design-baseline.zip` 和同目录 `manifest.json`；不得创建第二套 UI 参考替代它。本包不重复分发其字体、品牌素材或历史原型。

## 一句话完成定义

在目标 Mac 上，用户不运行开发服务，打开 Mokina.app，连接已有 Codex 能力，导入自己的资料，完成方案 → 单章修订 → 显式采用 → 选择性接续活动页 → 指定版本导出；退出和重开仍能继续工作，失败不会重复执行或改错成果。
