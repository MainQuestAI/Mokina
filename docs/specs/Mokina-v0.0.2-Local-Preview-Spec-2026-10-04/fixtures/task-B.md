# 任务 B｜实际操作

在任务 A 实际生成的指定旧版本中，仅选择“目标人群”和“核心传播策略”两个真实章节，使用选择性接续。添加本包品牌规则及 brand-mark.svg，目标类型选择活动页。

创建接续草稿后先检查来源、素材和版本，不发送。补充以下请求后再明确发送：

“请基于选定的人群与策略制作一份产品体验活动页，包含价值表达、产品事实、体验方式与行动入口。不要用大额折扣驱动，也不作健康功效承诺。当前没有真实报名后端，CTA 采用页面内跳转到体验说明，不能伪造提交成功。使用我选择的测试标识，输出可单章修订、可独立打开的 HTML。”

生成后选择一个真实章节修改文案，检查候选、不采用前的当前稿、采用后的新版本和旧版。分别导出两版 HTML/PDF/ZIP，并在应用外核对。
