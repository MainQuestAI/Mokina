# 任务 C｜开放式数据任务

分析 channel-performance.csv 的两期表现。金额单位人民币，时间按 Asia/Shanghai 的自然日期区间记录。

请核对记录数、缺失与零值，分别计算两期总花费、线索、收入、获客线索成本 CPL、ROAS，以及有在线曝光/点击口径的加权 CTR/CVR。不要将线下门店线索混入线上点击转化率分子，也不要把每个渠道的转化率简单平均。

解释线索变化主要对应哪些渠道，给下一步建议。数据只支持描述性关联，不足以证明因果。请给可核对表格、公式和记录定位，并输出可阅读的分析成果。再选择其中一条结论，创建一个可以继续讨论的独立草稿，不强制做活动页。
