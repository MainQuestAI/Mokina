# Mokina 活动页 HTML 约定

- **单个自包含 HTML 文件**：内联现代 CSS 与静态 `<svg>` 视觉插画/图表；图片仅使用本次选入并冻结的项目内相对路径或 `data:image/` 素材，不引用外链资源。
- **稳定顶层章节契约**：每个可修改的顶层章节同时使用稳定且唯一的 `id` 与同值 `data-mokina-id`（标准五章节：`hero`、`value`、`proof`、`cta`、`footer`）。章节之间不得嵌套；内部锚点只用普通 `id`；ID 不随标题措辞改变。
- **受众视角红线**：页面唯一受众为**外部目标客户 / 消费者**。严禁在可见正文中放置内部营销预算核算表（`data-mokina-budget`）、员工审稿工时、内部采购单价或“内部预览未批准”等工程审计话术。
- **说服主线（AIDA / FABE）**：`#hero`（为谁解决什么核心痛点 + 首屏行动按钮） → `#value`（三大核心利益 Bento 卡片 + 内联 SVG 机理图） → `#proof`（真实可查的产品参数/场景对比矩阵 + 面向客户的公开参数比值 `data-mokina-ratio`） → `#cta`（低摩擦转化入口与适用说明） → `#footer`（品牌与条款说明）。
- **受控语义编辑支持**：首屏主标题、副标题、核心利益点、参数矩阵单元格与 CTA 文案使用纯文本叶子元素标记 `data-mokina-field`（`data-mokina-kind="strategy"` 或 `"matrix"`），方便营销人员在界面中一键微调文案。
- **诚实交互与印刷兼容**：CTA 仅指向用户给定的合法目标或页内锚点（如 `href="#cta"`），无真实表单后端时注明预览态交互；包含 `@media print` 样式保证导出 PDF 时卡片与对比表不截断。
