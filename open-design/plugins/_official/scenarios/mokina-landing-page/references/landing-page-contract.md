# Mokina 活动页 HTML 约定

- 单个自包含 HTML 文件：内联 CSS 与 SVG；不引用项目内会漂移的图片、CSS、JS。选定素材无法内联时明确说明，不能声称可独立交付。
- 每个可修改的顶层章节同时使用稳定且唯一的 `id` 与同值 `data-mokina-id`，例如 `hero`、`value`、`proof`、`cta`、`footer`。章节之间不得嵌套；内部锚点只用普通 `id`；ID 不随标题措辞改变。
- 页面结构对应一条主线：人群 → 核心价值 → 事实与证据 → 行动入口。具体章节可按任务增删，但不得只剩空壳章节。
- 品牌规则：遵守禁用的表达与配色约束；图片只使用本次选定素材，保存图片不等于已完成视觉理解，未提供的视觉元素不得虚构。
- 行动入口：CTA 链接只指向用户给定的合法目标；没有表单后端时标记预览交互，不显示“提交成功 / 已发布 / 真实转化”一类回执。
- 数值与承诺：只用已有出处的事实与用户给定口径；估算与待核实项显式标注，缺失值不得当零或事实。
- 语言与可读性：正文可读性优先；不使用依赖悬停才能读到的关键信息；移动宽度下不出现横向溢出。
