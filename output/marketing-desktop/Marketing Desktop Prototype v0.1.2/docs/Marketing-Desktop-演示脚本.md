# Marketing Desktop 演示脚本

## 品牌战略

1. 打开 `Marketing Desktop Demo.html`，选择“品牌战略”。
2. 阅读工作计划：它只包含目标、输入、输出和排除项；保存计划本身不生成成果。
3. 生成演示成果，确认两份北岚生活访谈出现在依据快照，且成果明确排除 SKU 与上市链路。
4. 点击“编辑为候选”，修改“受众选择”并保存；在版本列表中对比 v1 与 v2，再采用选定版本。
5. 在对话框输入“保留方向，再补一个对照方案”，确认新增独立的家庭对照成果，而非覆盖原版。

## 社媒内容

1. 新建工作后选择“社媒内容”，生成五条文案与排期表。
2. 编辑第三条文案并保存候选；确认 v1 的其他四条仍保持原文。
3. 通过“导出”下载当前成果；它只包含本地成果文本，不表示已发布。

## 运营分析与接续

1. 选择“运营分析”，在“本次依据”查看已载入本地 CSV。
2. 计算后确认总体互动率 5.25% → 3.875%，下降 1.375 个百分点，以及“不判断两类内容都变差”的限制。
3. 点击“带入内容计划”，确认新工作只含选定结论的摘要，原分析和 CSV 仍在原工作中。

## V6.2 回归

从右上角“V6.2 专业流程”进入对照页，按现有 V6.2 验证清单复核德国七类交付、新产品输入、单渠道计划、候选决定、成员选择和固定提交。
